01 · Sobre mí

Entre el backend, los videojuegos y la IA

Soy Software Engineer en Buenos Aires. Hoy trabajo en Crisalu Games en Goblin Cleanup, un juego cooperativo para hasta 4 jugadores publicado por Team17 en Steam, donde me ocupo del guardado de partidas, la sincronización multiplayer y la integración con Steamworks.

Antes desarrollé en Java/Spring Boot para SIGERH, el sistema de recursos humanos de CONICET que usan más de 30.000 personas en todo el país.

Y antes de programar pasé 10 años en CONICET Documental, gestionando más de 300 TB de material audiovisual para más de 35 documentales. Tengo crédito en IMDb por la postproducción de Maelstrom: 2001. De ahí viene mi obsesión por no perder datos.

Uso IA como parte de mi forma de trabajar: agentes con Claude Code y MCP para revisar código, y la API de Claude para construir herramientas como Steam Review Insights.

    ★ Proyecto destacado

    Steam Review Insights

    API REST que importa las reseñas de Goblin Cleanup desde Steam y las clasifica con Claude en bugs, pedidos de mejora y comentarios positivos. Cada lunes, un flujo de n8n manda a Discord un resumen de la semana escrito por IA, con las reseñas destacadas y su link a Steam.

    • 449 bugs y 344 pedidos de mejora detectados en 24 idiomas, por menos de USD 1
    • 20 reseñas por llamada con structured outputs: ~USD 0,005 por lote
    • PostgreSQL + Flyway, Docker Compose, 25 tests con Testcontainers y CI
    • Java 21
    • Spring Boot 4
    • Claude API
    • PostgreSQL
    • Docker
    • n8n
    • GitHub Actions

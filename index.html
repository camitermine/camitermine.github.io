Steam Review Insights

API REST en Spring Boot que clasifica feedback de jugadores con Claude

Importa las 2.367 reseñas de Goblin Cleanup desde la API pública de Steam y las clasifica con Claude Haiku 4.5 en bugs, pedidos de mejora, comentarios positivos y otros, en 24 idiomas. Cada lunes, un flujo de n8n publica en Discord un resumen con los bugs y pedidos nuevos.

  • 449 reportes de bugs y 344 pedidos de mejora detectados, por menos de USD 1 en total.
  • 20 reseñas por llamada con structured outputs, y procesamiento por lotes que se retoma sin pérdidas si la API falla.
  • PostgreSQL con migraciones Flyway, Docker Compose, 25 tests con JUnit, Mockito y Testcontainers, y CI en GitHub Actions.

Java 21, Spring Boot 4, Anthropic Java SDK, PostgreSQL, Docker, n8n

      Tic-Tac-Fade

      Desarrollo asistido por IA, documentado como experimento

      Un tateti táctico multiplayer en Unity 6 donde cada jugador tiene como máximo tres fichas. Lo construyo de forma iterativa con Claude Code y el MCP de Unity, bajo mi supervisión. Cada iteración queda registrada: qué le pedí a la IA, qué produjo y qué tuve que corregir.

      • Las reglas viven en un módulo de dominio en C# puro, sin dependencias del motor, con 33 tests unitarios y reutilizable en el modo local, el online y un futuro oponente con IA.
      • Decisiones de arquitectura registradas en ADRs, e instrucciones del agente versionadas en el repo (CLAUDE.md).
